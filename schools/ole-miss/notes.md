# Ole Miss curation notes

## 1. Program status and coverage

Ole Miss is curated from program inception in 1908-09 through the completed 2025-26 season. The project owner has confirmed that Ole Miss is always top-level/D1 for site purposes from inception. The package contains **2,856 recognized non-exhibition varsity games**. Ole Miss played no games in 1917-18 during World War I; no synthetic rows are created.

## 2. Competitive-game count and on-court record

The detailed chronological source package contains **2,856 games and a 1,429-1,427 on-court record**. The historical ledger contributes 2,821 games; the owner-supplied completed 2025-26 season contributes 35 games and a 15-20 record.

## 3. 1913-14 internal source conflict

The Ole Miss media guide's 1913-14 season aggregate says **8-7**, while its detailed 15-game chronological ledger yields **9-6**. Independent aggregate evidence also supports 8-7, but research has not identified which specific chronological row is erroneous. The package therefore preserves all 15 printed game rows and explicitly documents the aggregate conflict rather than inventing a correction to a particular game.

This issue requires the normal Owner Gate historical-disposition decision before publication.
