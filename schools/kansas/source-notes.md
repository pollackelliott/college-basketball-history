# Kansas Source Notes

## Primary historical source

Official Kansas men's basketball media guide / year-by-year results. The game-by-game rows are the primary source for dates, opponents, scores, results, and source location text. Summary records and series tables are QA evidence.

## 2025-26

The curated 2025-26 seed contains 35 non-exhibition played games and a 24-11 record.

## Postseason sources

The user supplied Kansas NCAA and NIT appearance/result history. The official Kansas guide's dedicated postseason-history pages were used as the game-level cross-check, including its explicit statement that NCAA district playoff games do not count in NCAA Tournament totals. The guide's published 113-50 NCAA aggregate through 2025 reflects the vacated 2018 NCAA appearance; the project retains the five 2018 games and therefore uses the on-court tournament record.

The official Kansas Big 12 Championship results table identifies all Big 12 postseason tournament games and championship-game appearances through 2024-25. Big Eight postseason tournament games are derived from the year-by-year Kansas game log beginning with the 1976-77 postseason tournament. Old in-season Big Six/Big Eight holiday events are not reclassified as postseason conference tournaments.

Only title games receive `postseason_round = Championship`, whether Kansas won or lost.

## Administrative results

The Kansas source marks 15 2017-18 wins as later vacated. Those rows preserve the on-court W and score while carrying machine-readable administrative metadata.

## Venue sources

Venue assignments use the previously curated Kansas home chronology, game-level source location, event context, and prior cross-source reconciliation. Kansas City venue/site decisions remain game-specific.

## Source preservation

Source text is preserved even when a source aggregate, heading, or counterpart school assertion conflicts with the canonical interpretation. Conflicts are reconciled in the global discrepancy layer rather than silently rewriting the source assertion.
