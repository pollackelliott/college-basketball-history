# Northwestern Curation Notes

## Program status

Northwestern is curated through 2025-26 under the current project rules. Exhibitions and cancelled games are excluded from public competitive history.

## Game coverage

- Historical game rows through 2024-25: 2,795
- 2025-26 played games: 34
- Total non-exhibition played source rows: 2,829

Northwestern's media guide has an internal aggregate discrepancy. Summed season headings support 1,191-1,603-1 through 2024-25, while the guide quick-facts line says 1,111-1,603-1. Game rows remain the source of truth for canonical games; administrative/forfeiture-era effects are preserved as metadata rather than silently rewriting on-court results.

## Conference history

Northwestern has belonged continuously to the same league throughout its basketball history. The project uses the stable conference key `big-ten`.

Historical names supplied by the user:
- Western Conference — league founding in January 1895 through 1899
- Big Nine — 1899 through December 1916
- Big Ten — December 1916 to present
