# Kentucky Source Notes

## Primary historical source

Official University of Kentucky men's basketball record book / fact book, including year-by-year results, SEC Tournament history, and year-by-year NCAA Tournament history.

The main historical extraction contains 3,193 non-exhibition played rows through 2024-25. Three played 1988 NCAA Tournament games are absent from that year-by-year results section because they were later vacated; this package restores them from Kentucky's official NCAA Tournament history, bringing played historical coverage through 2024-25 to 3,196 games.

## 2025-26

The curated modern seed contains 36 played games and a 22-14 record. It includes three SEC Tournament games and two NCAA Tournament games.

## Source hierarchy

1. Kentucky year-by-year game rows for dates, opponents, scores, and base site evidence
2. Kentucky's dedicated SEC Tournament and NCAA Tournament history sections for postseason classification
3. User-supplied conference history and SEC champion/runner-up list as supplemental classification evidence
4. Opponent-school official/contemporary sources for cross-source reconciliation
5. Aggregate records and summary tables as QA evidence, not canonical game truth

## 1988 sanctions

Kentucky's official record book says the NCAA vacated all three 1988 NCAA Tournament games and the SEC stripped Kentucky's 1987-88 regular-season and tournament championships. It also explicitly says the regular-season and SEC Tournament games themselves were not forfeited. The package therefore separates the NCAA game-vacatur from the stripped SEC titles.

## Early conference-tournament naming

The detailed year-by-year game history labels the 1922 postseason event as the SIAA Tournament. For 1924, the detailed season page labels the event the Southern Conference Tournament, while a summary footnote appears to label that tournament differently. Since the project only exposes a generic conference-tournament game type and Kentucky's membership timeline is separately versioned, this internal naming discrepancy is documented without forcing an unsupported rewrite.
